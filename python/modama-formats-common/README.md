# modama-formats-common

Common file formats for the modama crawler (`python/crawler/`), as the format collection `common`: images, Python data science (notebooks, NumPy, HDF5, Zarr and their derivatives), office documents, plain text and structured data. Install it next to the crawler and the crawler finds it through the entry point group `modama.formats`; its format ids start with `common/`.

| Format | Recognised as | Extracted |
|---|---|---|
| Plain text, logs, READMEs (`text`) | each file the core types `text/plain` (`.txt`, `.asc`, text without a name rule), `text/x-log` (`.log`) or `text/x-readme` (`README` and the like) is one dataset (`common/text`, `common/log`, `common/readme`) | from the first 1 MiB (64 KiB of a file typed by its content, not its name): the encoding as the bytes say it (a BOM's, `ascii`, `utf-8`, else `Windows-1252`; none for a NUL byte) and the line count, for example `Windows-1252, lines 2` or `ascii, lines at least 20164` for a larger file, as `mapped_metadata`; never the text itself |
| Markdown (`text`) | `text/markdown` (`.md`, `.markdown`), one dataset each (`common/markdown`) | every entry of a YAML front matter, flat under its dotted name, dates as written, as `original_metadata`; the first heading, encoding and lines as `mapped_metadata`; for example `Lamella preparation, A. Example, 2026-11-12T10:00:00+01:00, ascii, lines 18` |
| reStructuredText (`text`) | `text/x-rst` (`.rst`), one dataset each (`common/rst`) | the title, subtitle and docinfo fields as docutils reads them (includes not followed), for example `Docutils Front-End Tools, David Goodger, 2024-12-04, utf-8, lines 570` |
| HTML (`text`) | `text/html` (`.html`, `.htm`), one dataset each (`common/html`) | from the head: `title`, `lang`, every `meta.<name>` but `meta.viewport`; text that is not UTF-8 decoded as the head declares; for example `Docutils Front-End Tools, David Goodger, Docutils 0.23: https://docutils.sourceforge.io/, utf-8, lines 1283` |
| LaTeX (`text`) | `text/x-tex` (`.tex`, `.sty`, `.cls`, …), one dataset each (`common/tex`) | every macro of the preamble with its first mandatory argument but definitions, packages and layout (`markup.LATEX_SKIPPED`), and `documentclass`, `title`, `author`, `date`, as raw LaTeX, for example `Docutils Front-End Tools, article, utf-8, lines 850` |
| BibTeX (`text`) | `text/x-bibtex` (`.bib`), one dataset each (`common/bibtex`) | the number of entries and their keys (no keys above 16), for example `entries 3, ascii, lines 22` |
| Office Open XML (`office`) | `.docx`, `.docm`, `.pptx`, `.xlsx`, `.xlsm` by name, a single file each (`common/docx` …) when it starts with a ZIP header; a misnamed file (a text file, an encrypted `.docx`, which is an OLE2 file) gets the type its content gives | a summary line of title, creator, created, application, pages or slides as the file writes them (`My Title, EJ04325S, 2011-07-29T16:52:00Z, Microsoft Office Word, Pages 1`). Values: every entry of the property parts the package's relationships name, as `core.<element>`, `app.<element>`, `custom.<name>`, as text (`original_metadata`); a presentation's slide count, a workbook's sheets with their dimensions by openpyxl's read-only mode, which also reads the shared strings (the cells' texts) and each sheet up to its `<dimension>`, not called when such a part is over 16 MiB (`mapped_metadata`). Never pictures or the document's other parts |
| OpenDocument (`office`) | `.odt`, `.odp`, `.ods` as the core types them, a single file each (`common/odt` …) when it starts with a ZIP header | a summary line of title, initial creator, creation date, generator and page count (`Apache Tika, Bart Hanssens, 2009-10-05T19:04:01, OpenOffice.org/3.1…, page-count 2`). Values: every child of `meta.xml`'s `office:meta` by its local name, attributes as `<name>.@<attribute>`, user-defined fields as `user-defined.<name>` (`original_metadata`); `encrypted` (`mapped_metadata`; an encrypted document's `meta.xml` is not read, and its summary line is `(encrypted)`) |
| PDF (`office`) | `.pdf` as the core types it, a single file (`common/pdf`) when `%PDF-` is in its first 1,024 bytes | a summary line of the Info dictionary's title, author, creation date, creator, producer and the page count (`Apache Tika - Apache Tika, Bertrand Delacrétaz, D:20070915110231+02'00', Firefox, Mac OS X 10.4.10 Quartz PDFContext, pages 1`). Values: every Info entry as `Info.<key>` and every XMP property as `XMP.<prefix>:<name>` (`original_metadata`); header, catalog version, page count, `encrypted` (`mapped_metadata`). By pypdf, given only a file with `%%EOF` at its end and at most 32 MiB to read; an encrypted file with the empty user password, as viewers open it (one that needs a password has the summary line `(encrypted)`); never the pages' content |
| Legacy Word, PowerPoint, Excel (`office`) | `.doc`, `.ppt`, `.pps`, `.xls` as the core types them, a single file each (`common/doc` …) when it starts with the OLE2 signature (an RTF file named `.doc` is RTF) | a summary line of title, author, creation time, application, page or slide count (`My Title, EJ04325S, 2010-10-05T09:03:00Z, Microsoft Office Word, num_pages 1`). Values: every property of the SummaryInformation and DocumentSummaryInformation sets under olefile's names, strings decoded with the file's code page, but the binary ones (`original_metadata`); user-defined properties are not read |
| Office lock files (`office`) | `~$name` as `application/x-ms-owner`, `.~lock.name#` as `application/x.libreoffice-lock`, by name, whatever the locked document's extension | nothing |
| TIFF (`image`) | a file of the core's type `image/tiff` (`*.tif`, `*.tiff`, or its header), one dataset (`common/tiff`); the name decides, nothing is read at recognition | through tifffile, the first page only: every tag under tifffile's name (a tag without one under its number), its value as tifffile reads it, the vendor blocks tifffile parses in tags flat under dotted names (`FEI_HELIOS.Beam.HV`, `CZ_SEM.ap_actualkv`, `ExifTag.…`), an ImageJ file's description and IJMetadata as `imagej_metadata.…`, its `Info` line by line (`imagej_metadata.Info.root.ApplicationBounds`, from `key = value` lines), as `original_metadata`; but one skip list (`tiff.skipped`: strip and tile offsets and byte counts, FEI's data bar settings, a value of more than 1 MiB of a tag tifffile reads on demand (it reads `ImageDescription`, `IJMetadata` and the offsets with the page, whatever their size), values not suitable for text); the first page's `first_page_shape`, `dtype`, `axes` as `mapped_metadata`. Summary line, for example `Helios NanoLab" 660, ETD, SE, HV 5000 (unit unknown), ImageWidth 512, ImageLength 471, BitsPerSample 8, 06/13/2016, 05:06:40 PM`. No page count: that walks every page |
| PNG, JPEG, BMP, GIF, WEBP (`image`) | a file of the core's type (`image/png`, `image/jpeg`, `image/bmp`, `image/gif`, `image/webp`), one dataset (`common/png`, …) | through Pillow, what `Image.open` reads before the image data: its `info` (PNG text chunks before the image data, JFIF, a comment as text), the EXIF block parsed by Pillow (`exif.Make`, `exif.Exif.ExposureTime`, `exif.Exif.ExifVersion`, `exif.GPSInfo.…`, `exif.Interop.…`; bytes as text where they are UTF-8; not the thumbnail's IFD1, not binary fields such as `MakerNote`: `pil.skipped`); `width`, `height`, `mode` and Pillow's `dpi` as `mapped_metadata`; for example `Canon, Canon PowerShot S40, width 480, height 360, 2003:12:14 12:01:44`. Pillow's decompression-bomb check is off (nothing is decoded); a compressed text chunk Pillow refuses as too large is left out with a `reader warning`. A WEBP of more than 16 MiB is not extracted (Pillow reads the whole file) |
| SVG (`image`) | a file of the core's type `image/svg+xml`, one dataset (`common/svg`) | through defusedxml, at most the first MiB, also within one large element: the root's attributes (`@width`, `@viewBox`, `@inkscape:version`) and the elements at the root that are not the drawing (`title`, `desc`, `metadata`, foreign metadata; `svg.skipped`: the SVG namespace's drawing elements and Inkscape's `sodipodi:namedview`) under dotted paths with the file's namespace prefixes (`metadata.rdf:RDF.cc:Work.dc:date`); for example `width 576pt, height 432pt` |
| EPS (`image`) | the core's type `image/x-eps`, no format | nothing: Pillow's reader reads the whole file to its end |
| JSON (`structured`) | `application/json` (`*.json`, a JSON value first; JSON Lines too), `application/schema+json` (`common/json`, `common/jsonschema`) | every value under its dotted path; several documents numbered |
| YAML (`structured`) | `application/yaml` (`*.yaml`, `*.yml`; `common/yaml`) | every value under its dotted path, keys and values as written; a stream's documents numbered |
| TOML (`structured`) | `application/toml` (`*.toml`; `common/toml`) | every value under its dotted path |
| CSV (`structured`) | `text/csv` (`*.csv`; `common/csv`) | the dialect, the header's names, columns and rows; no data row |
| XML (`structured`) | `application/xml` (`*.xml`, `<` first; `common/xml`), not its subtypes | every attribute and text, names with the file's prefixes; a text with a line break without its leading and trailing whitespace (pretty-printing) |
| INI, `.cfg` (`structured`) | `text/x-ini` (`*.ini`), `text/x-config` (`*.cfg`), a `[section]` first (`common/ini`, `common/cfg`) | every `section.key` |
| NumPy `.npy` (`pydata`) | `application/x-npy`, by its magic (`common/npy`) | the header (`numpy.lib.format`): `descr`, `fortran_order`, `shape`, version |
| NumPy `.npz` (`pydata`) | `application/x.npz`, by name, checked for a ZIP (`common/npz`) | each array's header, by NumPy's key |
| HDF5 (`.h5`, `.hdf5`, `.emd` …; `pydata`) | `application/vnd.hdfgroup.hdf5`, by its signature (`common/hdf5`) | h5py, a bounded walk (1,000 entries, 5,000 objects, 20 s): every attribute, each dataset's shape and dtype, scalar datasets' values; no array, no link to another file, nothing from outside the file (virtual datasets, external storage) |
| NeXus `.nxs` (`pydata`) | `application/x.nexus`, by name, checked for HDF5 (`common/nexus`) | as HDF5 (`NX_class` among the attributes) |
| HyperSpy `.hspy` (`pydata`) | `application/x.hspy`, by name, checked for HDF5 and HyperSpy (`common/hspy`) | as HDF5, without HyperSpy's internal state |
| MATLAB `.mat` (`pydata`) | `application/x-matlab-data`, by its header or name (`common/matlab`) | the header text; variables' shape and class (SciPy), version 7.3 as HDF5 |
| Jupyter `.ipynb` (`pydata`) | the core's `application/x-ipynb+json`, checked for a JSON object (`common/notebook`) | the notebook's metadata (nbformat), cell counts, the first heading; no outputs |
| Python scripts (`pydata`) | the core's `text/x-python`, `text/x-python3` (`common/python`, `common/python3`) | `ast`, never run: shebang, docstring, dunder names, imports |
| Pickles `.pkl`, `.pickle` (`pydata`) | `application/x-python-pickle`, by its start (`common/pickle`) | the protocol; never unpickled |

Each area (`image`, `pydata`, `office`, `text`, `structured`) is a subpackage added by its own change, with one import and one entry in `PARTS` in `src/modama_formats_common/__init__.py`, and its rows here. The YAML loader of every area is `src/modama_formats_common/yamldoc.py`: PyYAML's safe loader, with keys and plain values as the file writes them. Credentials are left out by the shared check `modama_crawler.formats.values.credential`.

## Values and units: what the file says

The principles of `python/modama-formats-em/README.md`, "Values and units: what the driver says", hold here too: an extractor shows what the file or its reader says, without editorializing (no rounding, no unit guessed or converted); what the file says comes first, every entry minus a skip list per format, never a list of wanted entries; values not suitable for text (too large, binary) are left out by the one check every collection shares, `modama_crawler.formats.values.textual`. The checklist for writing a format is `python/crawler/src/modama_crawler/formats/TEMPLATE.md`.

## Setup and tests

```bash
uv pip install --python ~/.venv/bin/python -e python/crawler[test] -e python/modama-formats-common[test]
cd python/modama-formats-common && pytest src
```

Each area is a subpackage of `src/modama_formats_common/` with its MIME rules, fixtures and tests, written as `python/crawler/src/modama_crawler/formats/TEMPLATE.md` describes; the crawler's pytest plugin runs them. Fixtures are public test data with their licence and source in `fixtures.toml`, or generated at test time.
